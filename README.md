# Space-Detective

TO RUN, MUST DOWNLOAD AND OPEN IN A BROWSER

This is a simple app to explore the space artifacts for NASA hackathon.

Space Detective is built with regular web technologies:

HTML & CSS: Builds the user interface, top scoreboard, on-screen controls, and pop-up windows.
HTML5 Canvas: Draws the 2D space maps, craters, rovers, and radar animations in real time.
JavaScript: Controls rover movement, collision detection, and the quiz system.
JSON (artifacts.json): Stores the data, facts, and quiz questions for all 13 NASA sites.
NASA Image API: Fetches real archival photos from NASA to display inside each pop-up.
